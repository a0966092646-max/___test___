# Boost Skill — 需求擴寫與執行工作流程

當使用者輸入 `/boost <簡短需求>` 時，依照以下三個階段執行。

---

## 階段一：擴寫專業提示詞（Prompt Engineering）

將使用者的簡短需求，擴寫成一份結構完整的專業 Prompt，輸出格式如下：

```
## 🚀 Boosted Prompt

**目標（Goal）**
一句話描述任務的核心目的。

**背景與情境（Context）**
說明使用場景、使用者身份、相關前提條件。

**具體需求（Requirements）**
- 需求 1
- 需求 2
- 需求 3（依實際情況列出 3–6 條）

**輸出格式（Output Format）**
描述期望的輸出形式（文件、程式碼、表格、清單等）。

**限制條件（Constraints）**
列出需避免或必須遵守的事項（若無則省略）。

**成功標準（Success Criteria）**
描述完成任務的驗收條件。
```

---

## 階段二：列出執行計畫

在開始實作前，以 `update_steps` 工具展示清楚的執行步驟清單，讓使用者了解接下來的行動順序。

格式範例：
1. 步驟一：分析需求與建立架構
2. 步驟二：執行核心實作
3. 步驟三：驗證與輸出結果

---

## 階段三：開始實作

確認執行計畫後，依步驟逐一完成任務。每完成一步，更新步驟狀態，並簡要說明結果。

---

## 注意事項

- 若需求過於模糊，可在擴寫後向使用者確認 1–2 個關鍵問題，再繼續執行。
- Boosted Prompt 應以**使用者的語言**（繁體中文）撰寫。
- 擴寫後的 Prompt 要能獨立使用——即使交給另一個 AI，也能清楚執行。
