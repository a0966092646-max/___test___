# 筆記格式規範（lesson-note-format）

在本專案建立任何 `.md` 筆記檔時，**必須**在檔案最上方加上以下 2 個區塊。

## 必要區塊格式

```markdown
## 建立日期

YYYY-MM-DD

## 重點摘要

> 在此填寫本筆記的核心重點（1–5 條）
```

## 操作步驟

1. 在寫入任何正文內容**之前**，先加上「建立日期」區塊，填入當天日期（格式：`YYYY-MM-DD`）。
2. 緊接著加上「重點摘要」區塊，提供摘要佔位文字 `> 在此填寫本筆記的核心重點（1–5 條）`。
3. 若使用者有提供具體摘要內容，直接填入；否則保留佔位文字讓使用者自行補充。
4. 在兩個區塊之後，再接正文內容。

## 範例

以下為符合規範的筆記檔案開頭：

```markdown
## 建立日期

2026-11-25

## 重點摘要

> - Python 的 try/except 用於捕捉例外狀況
> - finally 區塊無論是否發生例外都會執行
> - 可用 raise 重新拋出例外

## 正文內容

...
```
