# AI 程式實戰讀書會企畫書

> 建立日期：2026-11-25

---

## 一、讀書會簡介

| 項目 | 內容 |
|------|------|
| **主題** | AI 程式實戰 |
| **形式** | 線上讀書小組（Google Meet / Zoom） |
| **人數** | 2–6 人 |
| **頻率** | 每週一次 |
| **預計期程** | 1–3 個月 |

---

## 二、目標

- 系統性學習 AI 程式設計的核心概念與實作技術
- 透過每週討論，加深對內容的理解與應用
- 建立互相督促、共同成長的學習社群

---

## 三、進行方式

### 3.1 會議流程（每週）

| 時段 | 內容 |
|------|------|
| 開場（5 分鐘）| 本週主持人開場，回顧上週重點 |
| 討論（40 分鐘）| 針對本週指定章節進行分享與討論 |
| 重點整理（10 分鐘）| 主持人彙整本次討論重點 |
| 下週安排（5 分鐘）| 指定下週閱讀範圍，確認下週主持人 |

### 3.2 閱讀節奏

- 每次聚會後，由主持人指定下次的閱讀章節範圍
- 每位成員於下次聚會前獨立完成閱讀
- 閱讀時建議記錄自己的疑問、心得或有趣的段落，帶到討論現場分享

### 3.3 主持人輪流制

- 由成員輪流擔任每週主持人
- 主持人負責：
  - 準備 2–3 個討論引導問題
  - 控制會議時間
  - 彙整並記錄本次會議摘要
